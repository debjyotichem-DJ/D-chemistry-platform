## 🚀 How to Publish & Launch in 2 Minutes (Zero Cost)

### Option 1: Drag-and-Drop Deploy on Vercel (Easiest)
1. Unzip this package.
2. Go to [github.com](https://github.com) and create a repository named `d-chemistry-platform`.
3. Upload all files from this folder to the repository.
4. Go to [vercel.com](https://vercel.com), sign in with GitHub, click **Add New Project**, and select `d-chemistry-platform`.
5. Click **Deploy**. In under 60 seconds, your app will be live at `https://d-chemistry-platform.vercel.app`!

### Option 2: Run Locally on your Computer
```bash
npm install
npm run dev
```
